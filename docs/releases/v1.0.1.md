# 一二布布桌宠 1.0.1

> 本项目引用并参考 [ayangweb/BongoCat](https://github.com/ayangweb/BongoCat) 的桌宠交互设计，并以黄小B创作的一二布布表情包为角色参考。感谢两位原作者与社区的分享，让敲键盘、点鼠标也能拥有可爱的陪伴。

## 相比 1.0.0 的变化

- 标准 104 键的具体按键高亮，一二的小手平滑伸到对应键位，松开后返回。
- 支持双手和组合键；同一只手优先跟随最近按下的非修饰键。
- 布布的鼠标左键、右键、中键分别反馈；移除 R/L 字母。
- 移除输入内容预览条，优化圆润手臂、对称待机手和纯黑领结。
- 小键盘保持标准比例，键盘整体缩为 90%；空格靠近下巴，小键盘在画面最右侧。
- 翻转后的手部映射与高亮同步更新，被手臂挡住的组合键仍有细小标记。

## 下载与使用

下载 `YierBubu-v1.0.1-Windows-x64.zip`，完整解压后双击 `start.cmd`。升级前先从托盘退出旧版。

Windows 10/11 x64，需 .NET Framework 4.x。无需 Python、Rust、Node.js 或联网运行环境。

拖动可移动桌宠；Ctrl＋滚轮缩放；右键或托盘打开菜单。`app/config.ini` 可设置 width（120–1000）和 gap_ratio（0–0.15）。

## 验证

已完成 104 键高亮、26 个字母落点、组合键可见反馈、动作/返回/缩放恢复、待机对称、领结无遮挡、配置及 72 种头部/耳朵回归检查，并从新解压目录验证运行。

窗口 smoke 使用程序内快照，不注入系统按键。未在全部电脑、DPI 与多显示器组合上实测。
