# 一二布布桌宠 1.0.0 · 第一版封存

> 本项目引用并参考 [ayangweb/BongoCat](https://github.com/ayangweb/BongoCat) 的桌宠交互设计，并以黄小B创作的一二布布表情包为角色参考。感谢两位原作者与开源贡献者，让桌面互动既有趣又温暖。

这是第一版稳定封存，适合喜欢简单左右手联动的用户。

## 本版内容

- 一二响应全局键盘左右区域，可双手同时动作；本版尚未逐键定位。
- 布布根据鼠标方向转头，单手点击，另一只手放在腿上。
- 完整姿势互斥绘制，避免转头时耳朵重叠。
- 透明置顶、拖动、鼠标穿透、托盘菜单。
- 配置、自定义尺寸、菜单与 Ctrl＋滚轮缩放。

## 使用

下载 `YierBubu-v1.0.0-Windows-x64.zip`，完整解压后双击 `start.cmd`。

Windows 10/11 x64，需 .NET Framework 4.x。请保留 app 与 concept 的相对位置。

本版内部程序名 `YierBubu-v4.exe` 是制作时的迭代编号，不影响正式版本 1.0.0。

## 验证与范围

已完成本机 Windows x64 编译、键鼠状态与配置自测、72 种头部/耳朵像素回归以及便携解压运行检查。未在所有电脑与 DPI/多显示器组合上实测。
